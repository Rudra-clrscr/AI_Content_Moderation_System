Served from the API's own origin, so "Try it out" works without CORS. The /v1/moderate* endpoints need Authorize → Bearer (the SERVICE_TOKEN value) — unless it is unset, in which case they are open and GET /ready says service_auth: "open". Admin endpoints: sign in with POST /v1/admin/auth/login (email and password) and every admin call on this page works from then on, or use Authorize → AdminToken. Check GET /ready first — if the model did not load, moderation answers 503.
